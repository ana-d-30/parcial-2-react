# Quimix

## Descripción

Quimix es una aplicación desarrollada en React para la gestión de productos de laboratorio.

El sistema permite consultar productos, administrarlos y organizarlos por categorías mediante una interfaz sencilla e intuitiva.

---

## Tecnologías utilizadas

- React
- React Router DOM
- JavaScript
- CSS
- Vite

---

## Funcionalidades

- Inicio de sesión.
- Gestión de usuarios con roles.
- Cierre de sesión.
- Listado de productos.
- Detalle de productos.
- Gestión de categorías.
- Alta de productos.
- Edición de productos.
- Eliminación de productos.

---

## Roles

### Administrador

- Agregar productos.
- Editar productos.
- Eliminar productos.

### Usuario

- Consultar productos.
- Ver categorías.
- Ver detalle de productos.

---

## Instalación

1. Clonar el repositorio.

```bash
git clone https://github.com/ana-d-30/parcial-2-react.git
```

2. Instalar dependencias.

```bash
npm install
```

3. Ejecutar el proyecto.

```bash
npm run dev
```
